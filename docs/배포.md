# 배포

`breakkorean/docs/배포.md` 와 같은 얼개다. 다른 점만 이 파일에 적는다.

---

## 순서 — 받는 쪽 먼저

거꾸로 하면 그 사이 갈 곳 없는 주소가 생긴다.

```
1  도구      npm run deploy            (= check:links && wrangler deploy)
              → https://prelaps.com/imagesquish/ko/ 가 200 인 것을 눈으로 확인

2  라우터    prelaps-router 의 TOOLS 에 '/imagesquish' 한 줄
              npx wrangler deploy
              → 끝 슬래시 없는 /imagesquish 가 /imagesquish/ 로 301

3  허브      public/robots.txt · src/data/tools.ts · locales/*.json · {lang}/privacy
              npm run build && npx wrangler pages deploy dist --project-name prelaps-home
```

**push 는 배포가 아니다.** 무엇이 올라가 있는지는 status code 가 아니라
`npx wrangler deployments list` 로 확인한다.

## 배포 전 확인

```
□ npm run check:links      3장 · 0건이어야 한다
□ 세로로 찍은 아이폰 사진   결과가 눕지 않는지 (EXIF — 기획서 §5-1)
□ 투명 PNG → JPEG          투명한 자리가 검정이 아니라 흰색인지 (§5-4)
□ 모바일 사파리 실기기      여기가 제일 잘 죽는다 (§6)
□ 100장 / 300장 실측       기획서 §6 의 안내 문구 숫자를 실측값으로 고칠 것
                           지금 src/i18n.js 의 manyFiles 는 감으로 쓴 100 이다
```

`npm run check:links` 가 보는 것 중 눈으로는 못 잡는 두 가지:

- **언어 목록이 네 군데에서 같은지** — 폴더 / `worker/index.js` 의 `LANGS` /
  `src/i18n.js` 의 `STRINGS` / 각 페이지의 hreflang. `LANGS` 에만 언어를 적으면
  그 언어 브라우저 방문자 전원이 없는 주소로 302 를 맞는데, 한국어로 보는 사람에게는
  아무 일도 안 일어난다.
- **`data-*` 값을 번역해 버렸는지** — `data-fmt="image/webp"` 를 번역하면
  그 언어판만 설정이 통째로 안 먹는다.

## 검증 (배포 후)

| 주소 | 기대 |
|---|---|
| `/imagesquish` | 301 → `/imagesquish/` |
| `/imagesquish/` | 302 → `Accept-Language` 에 맞는 언어. `Cache-Control: no-store` |
| `/imagesquish/ko/` | 200 |
| `/imagesquish/en/` | 200 |
| `/imagesquish/ja/` | 200 |
| `/imagesquish/없는주소` | **404** (200 이면 soft 404 다) |
| `/imagesquish/styles.css` | 200 |
| `/imagesquish/sitemap.xml` | 200 |
| `/ko` | 200 — **허브다.** 라우트가 잘못 겹치면 여기가 먼저 죽는다 |

`Accept-Language` 별로:

```bash
for L in ko en ja de; do
  curl -sI -H "Accept-Language: $L" https://prelaps.com/imagesquish/ | grep -i '^location'
done
# ko→/ko/  en→/en/  ja→/ja/  de→/en/   (de 는 x-default 와 같아야 한다)
```

## og.png 다시 만들기

`test/og.html` 이 원본이다. 배포되는 파일이 아니라 그림을 만드는 틀이라 `site/` 밖에 있다.

```bash
npm run og        # 헤드리스 크롬으로 1200×630 스크린샷
```

크롬 경로가 다르면 `CHROME` 환경변수로 넘긴다.
문구를 고쳤으면 이걸 다시 돌려야 공유 썸네일이 따라간다 — 안 돌려도 화면에는 아무 표시가 없다.

## 언어를 하나 더 붙일 때

한 군데만 고치면 조용히 어긋난다. 다섯 곳이 같이 움직인다.

```
□ site/<언어>/index.html                새로 만든다 (ko 를 원본으로 삼아 번역)
□ 세 페이지 전부의 hreflang 목록        하나라도 빠지면 구글이 통째로 무시한다
□ site/sitemap.xml
□ worker/index.js 의 LANGS
□ src/i18n.js 의 STRINGS
□ 허브 src/data/tools.ts · locales/*.json · {lang}/privacy
```

`npm run check:links` 가 앞의 다섯을 검사한다. 허브 쪽은 검사하지 않으므로 눈으로 챙긴다.
